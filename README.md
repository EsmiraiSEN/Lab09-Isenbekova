## Что изучено

- **Строки в C# неизменяемы.** Методы вроде `ToUpper()` или `Replace()` не меняют исходную строку, а возвращают новую. Если просто написать `text.ToUpper();` без сохранения в переменную (например, `text = text.ToUpper();`), исходная строка останется прежней, и результат будет потерян.
- **Работа с индексами и циклом.** Строка — это по сути массив символов (`char`). По ней можно проходить циклом `foreach`, получать доступ к отдельным буквам через индекс (начиная с нуля) и определять длину с помощью свойства `.Length`.
- **Поиск и вырезание подстрок.** С помощью методов `Contains`, `StartsWith`, `EndsWith` можно проверять содержимое, а `Substring` позволяет вырезать нужную часть строки по индексу (например, чтобы разделить дату или отформатировать телефон).
